# 法界バトルアリーナ

仏教モチーフの演出を取り入れた、ローカル2人対戦のブラウザ格闘ゲームです。

## 遊び方

1. `index.html` をブラウザで開く。
2. プレイヤー1/2のキャラクターを選択。
3. 「対戦開始」を押してバトル開始。

## 収録キャラクター

- 阿弥陀如来
- 薬師如来
- 大日如来
- 不動明王
- 空海
- 最澄
- 親鸞
- 日蓮

それぞれ、教義・宗派のキーワードをモチーフにした必殺技演出を実装しています。

## 操作

### プレイヤー1
- 移動: `A` / `D`
- ジャンプ: `W`
- しゃがみ: `S`
- 弱攻撃: `F`
- 強攻撃: `G`
- 必殺技: `H`（気力50以上）

### プレイヤー2
- 移動: `←` / `→`
- ジャンプ: `↑`
- しゃがみ: `↓`
- 弱攻撃: `K`
- 強攻撃: `L`
- 必殺技: `;`（気力50以上）

## 備考

- 題材は敬意を持ったフィクションとして設計しています。
- ネット対戦は未対応（同一PCでのローカル対戦のみ）。
