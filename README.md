# デジタル人生絵巻 〜ライフラインで辿る私の歩み〜

高齢者向けに、自身の人生を4つの時代に分けて振り返る静的Webアプリです。
AIは使わず、選択したライフラインのパターン（高低差）をルールベースで5タイプに分類し、
心理学（エリクソンの視点）と仏教・ビハーラの視点からの温かいメッセージを表示します。

## 特徴

- インストール・会員登録不要。ブラウザだけで完結する単一の静的HTMLファイル（`index.html`）。
- 通信不要（外部ライブラリへの依存なし）で、入力内容は端末のブラウザ内にとどまり、サーバーには送信・保存されません。
- シニア向けUI：大きな文字（基本18px以上）、大きなボタン（高さ56px以上）、高コントラストな配色。
- 4つの時代（こども時代／わかい頃／あぶらの乗った頃／いま・これから）を5段階（嵐〜虹）で選ぶだけの簡単操作。
- 選んだ結果から、絵巻風のなめらかな折れ線グラフを自動描画。
- ライフラインの形（変曲点）から、以下5パターンに自動診断します。
  1. 大器晩成・波乱万丈型（山越え谷越えの道）
  2. 誠実・着実前進型（穏やかな川の流れ）
  3. 青春満開・追憶型（若き日の輝き道）
  4. 苦闘耐乏・慈愛型（風雪に耐えた道）
  5. 多彩な人生行路型（彩り豊かな道）
- 診断結果は画像として保存、または印刷が可能です。

## ローカルでの確認方法

`index.html` をブラウザで直接開くだけで動作します。

```bash
open index.html   # macOS
# もしくは
python3 -m http.server 8000  # http://localhost:8000/ にアクセス
```

## デプロイ（GitHub Pages）

`main` ブランチへの push をトリガーに `.github/workflows/deploy-pages.yml` が
GitHub Actions 経由で GitHub Pages へ自動デプロイします。

初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を
「GitHub Actions」に設定してください（一度設定すれば以降は自動でデプロイされます）。

デプロイ後のURL: `https://<owner>.github.io/<repository>/`
